
# Python Mini Projects 🐍

A collection of beginner-friendly Python projects built while learning Python programming and improving problem-solving skills.

## Projects

### 1. Guessing Number 🎯
A simple number guessing game where the user tries to guess a randomly generated number.

**Concepts Used:**
- `random` module
- User input and conditional statements
- Loops and basic logic

### 2. Password Generator 🔐
A Python program that generates random passwords using different characters.

**Concepts Used:**
- `random` module
- Strings and character selection
- User input and basic logic

## Technologies Used
- Python 3

## How to Run

1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder:
   ```bash
   cd YOUR_REPOSITORY_NAME
   ```

3. Run any project:
   ```bash
   python Guessing_number.py
   ```
   ```bash
   python password_generator.py
   ```
